# Algorithms and Data Structures

アルゴリズム・データ構造の学習用リポジトリです。
単なる実装集ではなく、以下を重視しています。

- アルゴリズムの目的
- どういう場面で使うか
- 計算量
- コメント付き実装
- 実行例

## 対象

### Sorting
- Quick Sort
- Merge Sort

### Graph
- BFS
- DFS
- Dijkstra

---

## なぜこのリポジトリを作るのか

エンジニアとして重要なのは、単にコードを書けることだけではなく、

- どの問題に対して
- なぜそのアルゴリズムを選び
- どの程度の計算量で
- どう実装したか

を説明できることだと考えています。

このリポジトリでは、実装だけでなく「なぜそれを使うか」も README やコメントで説明します。
