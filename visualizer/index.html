Algorithm Notes

Bubble Sort

隣り合う要素を比較し、必要なら交換する。動きが直感的で、可視化に向いている。

計算量: O(n^2)

Selection Sort

未整列部分から最小値を選んで先頭へ置く。比較と交換の役割を理解しやすい。

計算量: O(n^2)

Insertion Sort

左側を整列済みとして、要素を適切な位置へ挿入する。ほぼ整列済みの配列では効率が良い場合がある。

計算量: O(n^2)

Merge Sort

配列を分割してソートし、最後に統合する。分割統治法の代表例。

計算量: O(n log n)

Quick Sort

ピボットを基準に配列を分割していく。平均的に高速だが、最悪ケースでは O(n^2)。

計算量: 平均 O(n log n), 最悪 O(n^2)
