    Algorithm Notes

    Bubble Sort

    隣り合う要素を比較し、順番が逆なら交換する。動きが直感的で、学習向き。

    計算量: O(n^2)

    Selection Sort

    未整列部分から最小値を選んで先頭へ置く。比較と交換の違いを理解しやすい。

    計算量: O(n^2)

    Insertion Sort

    整列済み部分へ要素を差し込む。トランプを並べ替える感覚に近い。

    計算量: O(n^2)

    Merge Sort

    分割して整列し、最後にマージする。分割統治法の代表例。

    計算量: O(n log n)

    Quick Sort

    ピボットを基準に左右へ分けていく。平均的には高速。

    計算量: 平均 O(n log n), 最悪 O(n^2)

    BFS

    幅優先探索。キューを使って近いノードから順番に見る。重みなし最短経路に有効。

    DFS

    深さ優先探索。再帰やスタックで深く進む。連結成分や木構造の理解にも重要。

    Dijkstra

    重み付きグラフの最短経路。負の辺がないときに使う。優先度付きキューが重要。
